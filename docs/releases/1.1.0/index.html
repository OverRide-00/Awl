AAwl1.1.0
Update · 1.1.0

Faster search.
Better capture.

Awl 1.1.0 fixes generic taskbar icons for packaged apps, shows a still frame before you play a recording, adds file actions to Capture, makes Quick Search responsive while typing, and adds a taskbar kill command.

What changed

App iconsTaskbar windows now use their packaged app identity or window icon before falling back to the executable. This fixes icons for apps such as Settings and WhatsApp.
Capture previewThe saved clip review shows an actual frame from the recording before playback starts.
Compress or convertSend a new recording or screenshot straight from Capture review to Quick Search’s file tools.
Quick SearchFile ranking no longer reads timestamps from disk on each keypress, and result updates wait briefly for typing to settle.
Taskbar kill commandRight-click an app and choose “Kill app and background processes” to end its matching instances. Shared Windows shell processes stay protected.
