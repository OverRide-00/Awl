Release · 0.1.1

Updates are live

Awl now has a complete GitHub release and update pipeline.

What's new

  • Release, Beta, and Alpha update channels in General settings.
  • Automatic update checks and a themed install prompt.
  • SHA-256 verification before an update replaces the running executable.
  • Dev Mode can build and publish a versioned update with attached HTML release notes.
  • Older executable releases remain available for download.

The What's New action now opens the readable GitHub release page.
