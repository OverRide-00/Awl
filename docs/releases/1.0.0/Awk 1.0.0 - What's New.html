01 / Extend

Find what Awl can become.

The in-app browser separates plugins, templates, and icon packs. Core and Visual filters, categories, sorting, and search help narrow the catalog.

Plugin discovery

Everything stays inside the app.

Browse the plugin catalog without leaving Awl. Open a listing for details, then install, update, enable, or remove it from the same workspace.

  • Motion API gives plugins procedural animation support.
  • Ratio keeps widget positions proportional across display sizes.
  • Motion Showcase adds visual motion to Awl’s surfaces.
Templates

Save a whole setup.

The template gallery collects wallpaper, color, icon, and settings choices. In-built templates can carry the plugins they need, while personal templates stay in their own group.

The local template names and wallpapers shown here are examples from the captured session.

02 / Personalize

Fine-tune the entire shell.

Awl can derive a palette from the wallpaper or use your own color overrides. Interface controls let you adjust opacity, motion, window appearance, and scale.

03 / Control

Put every control where it belongs.

Configure shortcuts for opening Awl, Quick Search, Capture, Hidden Mode, and more. Reorder top-bar modules or choose how the taskbar and displays work.

Shortcuts

Record new bindings, reset them, and optionally use Print Screen for Awl Capture.

Top-bar modules

Reorder modules, assign a side, and switch individual items on or off.

Taskbar and displays

Set icon spacing and alignment; choose primary, duplicated, or individual display layouts.

Elsewhere in 1.0.0

More than the screens can show.

These features are part of the same release.

Quick Search and file tools

Find apps and files, calculate, convert units, compress a file, or choose an output format for conversion.

Capture and recording

Take a region, window, or full-screen capture with live recording time, quality controls, and review tools.

Motion and layout plugins

Procedural motion adds animated surfaces and taskbar interactions. Ratio helps widgets keep their positions across displays.

Dev Mode

Create persistent in-built templates and test a clean Awl build with only their required plugin assets.
