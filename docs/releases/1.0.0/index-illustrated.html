The big additions

Three new ways to use Awl.

Each preview below is an interactive illustration of the feature. The controls on this page demonstrate the flow without changing your computer.

01 / Extend

A plugin system for the whole shell.

Install Core plugins for actions, tabs, toolbar modules, services and Quick Search calculators. Visual plugins can restyle Awl and add motion profiles. Browse, enable, update and remove them from Awl.

  • Core and Visual plugins can work separately or together.
  • Template dependencies travel with built-in presets and activate when the template is applied.
  • Motion API and Ratio provide reusable animation and layout services for plugins.

02 / Find

One search for more than apps.

Open Quick Search with Ctrl + Alt + Space. Find apps, files and settings; calculate expressions; convert units and currency; or open the new file conversion and compression tools.

  • Fuzzy matches tolerate partial names and separators.
  • Instant answers for math and unit conversion.
  • File tools support drag-and-drop, format selection and compression strength.

03 / Capture

Capture the moment, your way.

The redesigned Capture bar lets you choose a region, window or full screen. Take a screenshot, record video, pause and resume, adjust quality, or save a recent moment from the optional replay buffer.

  • Compact recording controls show live time, size and quality.
  • Save last 30 seconds is available when replay is enabled.
  • Review and export captures after recording.

More additions

The rest of the 1.0.0 toolbox.

New customization, organization and developer controls added since 0.2.1.

◇

Icon packs

Import or browse packs, switch between outline, filled and colorful styles, and optionally replace matching application icons.

◐

Component colors

Keep wallpaper-driven colors or override individual surfaces, text and icons. Custom colors can be saved into templates.

✧

Motion and layout

Visual motion profiles animate menus, search, taskbar and capture surfaces. Ratio keeps layouts proportional across display sizes.

⌘

Keyboard shortcuts

Record or clear global shortcuts. Hidden Mode and an optional Print Screen replacement are available in General settings.

▦

Template gallery

Browse templates alongside My, Imported, Public and In-built groups. Dev Mode persists its template library and builds four presets into this release.

↺

Version switcher

Dev Mode lists published builds, compares changes and verifies cached releases before testing them in an isolated session.

≋

Taskbar motion

Active windows can promote smoothly in the taskbar, with hover and app launch motion controlled by a visual profile.

⇄

Quick file tools

Convert supported image, audio, video and document files or compress a file from Quick Search with visible progress.

⬡

Plugin authoring

New package scripts, catalog metadata and SDK documentation cover Core actions, visual styles, shared services and semantic icons.

▣

App actions

Open an app's location in File Explorer or launch its registered uninstaller from Awl. Ambiguous uninstall commands fall back to Windows Settings.

◨

Window appearance

Fine-tune Awl surface opacity, per-surface scale, window corner presets, shadows, snap assistance and the cursor style.

☼

Wallpaper handoff

Return to Wallpaper Engine from Awl's wallpaper controls, with the selected project restored after startup when available.

Bug fixes and refinements

Smoother where it counts.

These changes address behavior in 0.2.1 or during the development of 1.0.0.

✓
Recording time stays in step

Capture now uses a shared clock for video frames and the recording timer, including pause and resume, reducing fast or uneven playback.

✓
Replay does not run by default

The rolling recorder is opt-in, and background maintenance stops it when disabled instead of keeping capture work active.

✓
Window changes restore cleanly

Window customization, animation cloaks and taskbar tracking are restored or stopped when Awl exits.

✓
Template plugin state is preserved

Template builds include only required plugin assets; required plugins activate when the template is applied, without pre-enabling them for every user.

✓
Controls remain responsive

Switch motion preserves the click action, while search reveal and visual effects are canceled cleanly when interrupted or disabled.

✓
Wallpaper playback recovers

Awl waits for its own video to be ready before stopping Wallpaper Engine, and resumes Wallpaper Engine if that video cannot play.

✓
Publishing can resume

The release workflow now sends UTF-8 metadata, streams large assets and can resume an incomplete release without restarting Dev Mode.
