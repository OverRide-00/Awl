Release · 0.1.0

Awl is ready

The first public Awl build brings the shell, widgets, visual Widget Builder, capture tools, templates, and isolated Dev Mode together as standalone Windows applications.

Included

  • Custom start menu, taskbar, pinned views, toolbar, notifications, and Alt+Tab.
  • Desktop widgets with live editing, anchors, snapping, templates, glass, and wallpaper colors.
  • Standalone Widget Builder with UI layers, live data, formatting, and logic flows.
  • Screenshot and recording controls with Discord-oriented size presets.
  • GitHub update channels with verified in-app installation.

Thank you for trying Awl.
