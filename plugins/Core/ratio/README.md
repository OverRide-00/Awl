# Awl Ratio

Awl Ratio adds **Display ratio** to the Interface tab. Select **Set ratio from this display** to capture the current virtual-screen width, height, and the Date & Time and Recents widget locations.

When Windows reloads or changes the display, the plugin maps each saved location proportionally to the new virtual screen. For example, a widget saved at `(3, 7)` on a `10 × 10` display is placed at `(30, 70)` on a `100 × 100` display.
